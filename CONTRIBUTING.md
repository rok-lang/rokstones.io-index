# Contributing

This repository is the rokstones.io package registry index. It is not a code
project: it holds one file per published stone.

## Publishing a stone

See the README for the layout and the publish flow (`rok publish` writes the
index line; a maintainer merges the pull request). Names that differ only in
case or in `-` / `_` are the same stone.

## Reporting a problem

Open an issue for a malformed entry, or report a malicious stone privately (see
SECURITY.md).
